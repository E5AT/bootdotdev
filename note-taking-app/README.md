# Note Taking App

A simple CLI note-taking app written in Python. You can add notes, list them all, or delete one by its ID. Notes are stored in a local `notes.json` file.

## How to run

```bash
git clone https://github.com/E5AT/bootdotdev.git
cd bootdotdev/note-taking-app
python main.py add "your note here"
python main.py list
python main.py delete 0
```
